# raw/ — sources brutes (immuables)

Dépose ici tes sources : articles (Obsidian Web Clipper → markdown), PDF, transcripts,
captures, notes, exports de data. **Ne jamais modifier** un fichier ici : c'est la source
de vérité. Images dans `raw/assets/`.

Pour ingérer une source dans le wiki :

```
/ingest raw/mon-article.md
/ingest https://exemple.com/article
```

Le reste (résumé, pages entités/concepts, index, log) est géré automatiquement par l'agent.
